# 🧠 Quiz Generator

A simple and interactive **Quiz Generator web application** that allows users to generate and attempt quizzes through a clean and user-friendly interface.

## 🚀 Features

* 📝 Generate and attempt quiz questions
* 🎯 Multiple-choice questions
* ⚡ Interactive quiz experience
* 📊 Displays quiz results
* 📱 Responsive user interface
* 🎨 Clean and simple design
* 🔄 Restart quiz functionality

## 🛠️ Technologies Used

* **HTML5** – Page structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Quiz logic and interactivity
* **Git & GitHub** – Version control and project hosting

## ⚙️ How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/vireshaijeri5-web/quiz-generator.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

Or use **Live Server** in VS Code for a better development experience.

## 🎮 How It Works

1. Start the quiz.
2. Read each question carefully.
3. Select the correct answer.
4. Move to the next question.
5. Complete the quiz.
6. View your final score.

## 🎯 Project Objective

The main objective of this project is to build an interactive web application while practicing **HTML, CSS, JavaScript, DOM manipulation, event handling, and frontend development concepts**.
